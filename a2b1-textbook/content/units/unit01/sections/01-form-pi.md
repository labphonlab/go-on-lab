## Language Focus①：解釈タスク

まずは「意味を正しく聞き分ける」練習です。まだ自分では書きません。文をよく読んで、意味を選びましょう。

### タスク A（客観的な解釈）

それぞれの文が (a) 「前から決めていた予定」と (b) 「今その場で決めたこと」のどちらを表しているか、○をつけましょう。

1. A: We need more drinks for the party.　B: Okay, **I'll buy** some on my way home.
   → ( a. 前から決めていた予定 ／ **b. 今その場で決めたこと** )

2. I **'m going to visit** my grandmother next Sunday. I already told her.
   → ( **a. 前から決めていた予定** ／ b. 今その場で決めたこと )

3. A: Oh no, it's raining and I don't have an umbrella!　B: Don't worry, **I'll drive** you home.
   → ( a. 前から決めていた予定 ／ **b. 今その場で決めたこと** )

4. Ben **is going to meet** Aya at one o'clock. They planned it yesterday.
   → ( **a. 前から決めていた予定** ／ b. 今その場で決めたこと )

5. A: What are your plans for Saturday?　B: I**'m going to watch** a movie with my sister.
   → ( **a. 前から決めていた予定** ／ b. 今その場で決めたこと )

### タスク B（提案の丁寧さを聞き分ける）

それぞれの文が「丁寧な提案」か「カジュアルな提案」か、印をつけましょう（正解は一つに決まらない場合もあります。話す相手や場面を考えて選んでください）。

6. **Shall we** start the meeting now?　→ ( **丁寧** ／ カジュアル )
7. **Why don't we** get some coffee first?　→ ( 丁寧 ／ **カジュアル** )
8. **Shall we** go to the museum together?　→ ( どちらも自然。フォーマルな場面なら丁寧、友人同士ならカジュアルにも聞こえます )
