### タスク A（規則動詞か不規則動詞か）

それぞれの過去形が (a) 「規則動詞（-ed を付けた形）」と (b) 「不規則動詞（形が変わる）」のどちらか、○をつけましょう。

1. I **cleaned** the house on Tuesday.
   → ( **a. 規則動詞** ／ b. 不規則動詞 )
2. Jack **brought** some groceries to his grandmother.
   → ( a. 規則動詞 ／ **b. 不規則動詞** )
3. I **visited** my cousin last month.
   → ( **a. 規則動詞** ／ b. 不規則動詞 )
4. We **took** a short trip with my family.
   → ( a. 規則動詞 ／ **b. 不規則動詞** )
5. Jack **reviewed** for a test on Saturday.
   → ( **a. 規則動詞** ／ b. 不規則動詞 )

### タスク B（出来事の順番を読み取る）

次の文を読んで、出来事が起きた順番に 1〜4 の番号をつけましょう。

- ( 　1　 ) First, I cleaned the house.
- ( 　4　 ) Finally, I made dinner.
