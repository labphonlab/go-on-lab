今度は自分で文を作ります。（　）の動詞を正しい過去形にしましょう。

1. Last week, I ( clean ) my room on Saturday morning. → **cleaned**
2. Jack ( have ) a meeting with his boss and a colleague. → **had**
3. After work, we ( go ) shopping and ( buy ) some groceries. → **went / bought**
4. My neighbor ( bring ) some mail to my house by mistake. → **brought**
5. On Sunday, my family and I ( take ) a short trip to the beach. → **took**
6. I ( study ) all day and ( review ) for a big test. → **studied / reviewed**

### 順番につなげてみよう

**First**、**Then**、**After that**、**Finally** を使って、次の出来事を順番につなげた文を書きましょう。

7. woke up late → had coffee → jogged in the park → felt great：

   _____________________________________________

8. cleaned the house → did the dishes → relaxed on the sofa → watched TV：

   _____________________________________________

### 短い自由作文

先週（last week）の出来事を、2〜3文で時系列に書いてみましょう。**first / then / after that / finally** のうち、少なくとも2つを使い、過去形の動詞を使ってください。
