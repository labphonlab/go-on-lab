まずは「意味を正しく聞き分ける」練習です。まだ自分では書きません。文をよく読んで、意味を選びましょう。

### タスク A（経験 vs. 特定の過去の出来事）

それぞれの文が (a) 「今までの経験（いつかは大事ではない）」と (b) 「いつ・どこであったか、はっきり決まっている過去の出来事」のどちらを表しているか、○をつけましょう。

1. I **have visited** Thailand twice.
   → ( **a. 今までの経験** ／ b. 特定の過去の出来事 )

2. I **visited** Thailand last year with my family.
   → ( a. 今までの経験 ／ **b. 特定の過去の出来事** )

3. **Have** you ever **eaten** curry?
   → ( **a. 今までの経験** ／ b. 特定の過去の出来事 )

4. We **ate** curry last night at a new restaurant.
   → ( a. 今までの経験 ／ **b. 特定の過去の出来事** )

5. Mei **has seen** a famous singer before.
   → ( **a. 今までの経験** ／ b. 特定の過去の出来事 )

6. Mei **saw** a famous singer at the airport last month.
   → ( a. 今までの経験 ／ **b. 特定の過去の出来事** )

### タスク B（ever / never の意味を聞き分ける）

それぞれの文の意味として正しい方を選びましょう。

7. Have you **ever** ridden a roller coaster?
   → ( **今までに一度でも乗ったことがあるか、たずねている** ／ 昨日乗ったかどうか、たずねている )

8. I have **never** climbed a mountain.
   → ( 今までに何回も山に登った ／ **今まで一度も山に登ったことがない** )

### タスク C（自分ならどう思うか）
