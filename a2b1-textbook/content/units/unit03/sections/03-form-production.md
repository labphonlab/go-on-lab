今度は自分で文を作ります。（　）に **have/has + 過去分詞** の正しい形を書きましょう。

1. A: ( 　　　 ) you ( 　　　 / travel ) abroad? B: Yes, I have. I traveled to Thailand last year. → **Have / traveled**
2. Jack ( 　　　 / ride ) a roller coaster many times. He loves them. → **has ridden**
3. I ( 　　　 / eat ) very spicy curry before, so I know it's hot! → **have eaten**
4. Mei ( 　　　 / never / climb ) a mountain in the winter. → **has never climbed**
5. A: ( 　　　 ) you ( 　　　 / see ) a famous singer? B: No, I ( 　　　 ). → **Have / seen** / **have not**

### 経験をたずねてみよう

**Have you ever 〜?** を使って、次の話題について質問する文を書きましょう。

6. 海外旅行の経験について：_____________________________________________
7. 珍しい食べ物を食べた経験について：_____________________________________________
8. 何かの乗り物に乗った経験について：_____________________________________________

### 短い自由作文

今までにしたことがある経験を、2〜3文で書いてみましょう。**have/has + 過去分詞** を少なくとも1回、**ever** か **never** を少なくとも1回使ってください。
