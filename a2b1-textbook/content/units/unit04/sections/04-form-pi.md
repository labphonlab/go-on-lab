まずは「意味を正しく読み取る」練習です。まだ自分では書きません。文をよく読んで、正しい答えを選びましょう。

### タスク A（比較級・最上級の意味）

それぞれの文を読んで、正しい方に○をつけましょう。

1. My apartment is **smaller** than yours.
   → あなたの部屋の方が ( **大きい** ／ 小さい )

2. This cafe is **quieter** than that one.
   → that one（あの店）の方が ( **うるさい** ／ 静か )

3. Tokyo is **more expensive** than Osaka.
   → Osaka の方が ( **安い** ／ 高い )

4. This restaurant is **the best** one in town.
   → 町の中に、ここより良いレストランは ( ある ／ **ない** )

5. Her new phone is **cheaper** than her old one.
   → 新しい携帯電話の方が ( **安い** ／ 高い )

### タスク B（as ~ as の意味）

それぞれの文が「同じくらい」を表しているか、「同じくらいではない」を表しているか、○をつけましょう。

6. Bag A is **as expensive as** Bag B.
   → ( **同じくらいの値段** ／ 値段が違う )

7. This hotel **isn't as clean as** that one.
   → ( 同じくらいきれい ／ **this hotel の方がきれいではない** )

8. My city is **as safe as** yours.
   → ( **同じくらい安全** ／ 安全さが違う )
