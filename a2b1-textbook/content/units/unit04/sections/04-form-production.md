今度は自分で文を作ります。（　）に形容詞の正しい形（比較級・最上級）を書きましょう。

1. This apartment is ( 　　　 / cheap ) than that one. → **cheaper**
2. My old phone was ( 　　　 / good ) than my new one. → **better**
3. Of all the cafes near the station, this one is ( 　　　 / popular ) café in town. → **the most popular**
4. Her new kitchen is ( 　　　 / small ) than her old kitchen. → **smaller**
5. This neighborhood is ( 　　　 / safe ) than that one. → **safer**

### 比べてみよう

次の二つの物や場所について、比較級を使って1文ずつ書きましょう。

6. あなたの部屋（room）と、友だちの部屋を比べて：_____________________________________________
7. 二つのカフェやレストランを比べて：_____________________________________________
8. 二つの街や場所を比べて：_____________________________________________

### as ~ as を使ってみよう

**as ~ as**（または **not as ~ as**）を使って、次の文を完成させましょう。

9. My bag is ( 　　　 ) expensive ( 　　　 ) yours. → **as / as**
10. This apartment isn't ( 　　　 ) quiet ( 　　　 ) the other one. → **as / as**

### 短い自由作文

あなたが知っている二つの場所（カフェ、レストラン、部屋など）を比べて、2〜3文で書いてみましょう。比較級を少なくとも1回、**as ~ as** を少なくとも1回使ってください。
