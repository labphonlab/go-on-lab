対話をもう一度見て、太字の部分に注目しましょう。

> Ben: The second one is **far**, but it's much **cheaper**.
> Ben: The kitchen in the second one is **smaller**, but it's **newer**.
> Aya: Is the second one **as convenient as** the first one?
> Ben: The first one is **more convenient** because it's **closer** to the supermarket.
> Ben: I think the second one is **better** for me.
> Aya: I think the second one sounds like the **best** choice for you.

### 日英対照

| 英語 | 意味・使うタイミング | 日本語での近い感覚 |
|---|---|---|
| **短い形容詞 + -er + than** | 二つを比べて「どちらがより〜か」を言う | 「〜より…だ」 |
| **more + 長い形容詞 + than** | 音節の多い形容詞の比較級 | 「〜よりもっと…だ」 |
| **the + 短い形容詞 + -est** | 三つ以上の中で「一番〜」を言う | 「一番…だ」 |
| **the most + 長い形容詞** | 音節の多い形容詞の最上級 | 「一番…だ」 |
| **A as 形容詞 as B** | AとBが「同じくらい〜」であることを言う | 「AはBと同じくらい…だ」 |
| **not as 形容詞 as** | 「〜ほど…ではない」 | 「〜ほど…じゃない」 |

### 気づきポイント

1. **cheap（安い）→ cheaper（もっと安い）**、**small（小さい）→ smaller（もっと小さい）**のように、短い形容詞は語尾に **-er** をつけます。**quiet → quieter**、**noisy → noisier**、**safe → safer** も同じパターンです（noisy は y を i に変えて -er）。
2. **convenient（便利な）** は音節が多い形容詞なので、語尾を変えず前に **more** をつけて **more convenient** にします。**-er** は付けません。
3. **good（良い）→ better（もっと良い）→ the best（一番良い）** は不規則な変化です。**-er** や **-est** をつけないので、そのまま覚えましょう。
4. Aya の "**as convenient as** the first one?" は、「二番目のアパートは一番目のアパートと同じくらい便利？」という意味です。Ben の答え "No" は、二番目の方が便利ではない（**not as convenient as**）ということを表しています。

**確認問題**：対話の中から、比較級（-er または more）が使われている文をもう一つ探して、下に書いてみましょう。
