正しい形を（　）に書きましょう。

1. A: What are your plans for tonight? B: I ( 　　　 ) watch a movie with my sister. → **am going to / 'm going to**
2. She ( 　　　 ) (visit) her cousin last Sunday. → **visited**
3. ( 　　　 ) you ever (eat) sushi? → **Have ... eaten**
4. This book is ( 　　　 ) (interesting) than that one. → **more interesting**
5. My phone is ( 　　　 ) as new ( 　　　 ) yours. → **as / as**

次の文章の空らんに、文脈に合う形を書いて、自分の先月について書いてみましょう（be going to、過去形、現在完了、比較級を少なくとも1回ずつ使ってください）。

```
Last month, I ______________________________.
I have ever ______________________________.
This month, my plan is ______________________________.
Compared to last month, this month is ______________________________.
```
