まずは「意味を正しく聞き分ける」練習です。まだ自分では書きません。文をよく読んで、意味を選びましょう。

### タスク A（場所の説明を読み取る）

次の説明を読んでください。

> On Main Street: the bakery is next to the bank. The library is across from the bakery. The gas station is behind the library. The bookstore is in front of the station, near the corner.

それぞれの文が正しいか、正しくないか、○をつけましょう。

1. The bakery and the bank are next to each other. → ( **正しい** ／ 正しくない )
2. The library is next to the gas station. → ( 正しい ／ **正しくない** )
3. The bookstore is far from the station. → ( 正しい ／ **正しくない** )
4. The gas station is behind the library. → ( **正しい** ／ 正しくない )

### タスク B（命令文の意味を聞き分ける）

それぞれの命令文が、地図上でどの動きを表しているか選びましょう。

5. **Go straight** along this street. → ( 同じ方向にまっすぐ進む ／ 向きを変える )　→ **同じ方向にまっすぐ進む**
6. **Turn left** at the corner. → ( 同じ方向にまっすぐ進む ／ **向きを変える** )
7. **Cross the street.** → ( 道の反対側に渡る ／ 道に沿って歩く )　→ **道の反対側に渡る**
8. **Keep going** until you see the sign. → ( 止まる ／ **進み続ける** )

### タスク C（丁寧さを聞き分ける）

それぞれの表現が「とても丁寧」か「直接的（friendly だが命令に近い）」か、印をつけましょう（正解は一つに決まらない場合もあります。話す相手や場面を考えて選んでください）。

9. **Turn left at the corner.** → ( とても丁寧 ／ **直接的** )
10. **Could you tell me the way to the station?** → ( **とても丁寧** ／ 直接的 )
11. **Would you like me to write down the directions?** → ( **とても丁寧** ／ 直接的 )
