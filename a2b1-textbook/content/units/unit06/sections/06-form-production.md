今度は自分で文を作ります。（　）に動詞の命令形か、場所の前置詞を書きましょう。

1. A: Excuse me, how do I get to the library?　B: ( 　　　 ) straight along this street. → **Go**
2. When you get to the traffic light, ( 　　　 ) left. → **turn**
3. The bank is ( 　　　 ) the supermarket, so they're easy to find together. → **next to**
4. The pharmacy is ( 　　　 ) the gas station — you'll see it right away when you come out. → **opposite / across from**
5. Don't stop at the corner. Just ( 　　　 ) going until you see the sign. → **keep**
6. The bookstore is ( 　　　 ) the station, so you can see it as soon as you arrive. → **in front of**

### 丁寧にお願いしてみよう

**Could you** または **Would you** を使って、次の場面でお願いする文を書きましょう。

7. 知らない人に、駅までの道を尋ねたいとき：_____________________________________________
8. 地元の人に、地図を書いてほしいとお願いしたいとき：_____________________________________________
9. 誰かに、もう一度ゆっくり説明してほしいとお願いしたいとき：_____________________________________________

### 短い自由作文

あなたの家から近くのコンビニ（convenience store）や図書館（library）までの行き方を、2〜3文で書いてみましょう。命令文（imperative）を少なくとも1回、場所の前置詞を少なくとも1回使ってください。
