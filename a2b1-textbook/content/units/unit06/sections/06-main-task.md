**紙面での準備（アプリを使う前に）**

1. あなたが行きたい場所を1つ選びましょう（駅 / 図書館 / コンビニ）。
2. Grace（AI の地元の人）は、その場所までの道順を知っています。あなたは知りません。質問して聞き出しましょう。
3. 次の表現を最低1回ずつ使うことを目標にします。

   - **Excuse me** で会話を始める
   - **Could you / Would you** で丁寧にお願いする
   - 道順について質問する（例：*Is it far from here? Which street should I take?*）
   - 最後に、聞いた道順を自分の言葉で言い直して確認する（例：*So I go straight, then turn left at the bank?*）

**アプリでのロールプレイ**

QR コード（このユニットの先頭）または `learn.goonresearch.jp/u/6` からアプリを開き、"Main Task: Roleplay" を選んでください。Grace と英語でやり取りしながら、目的地までの道順を聞き出しましょう。会話が終わると、AI が達成度を確認してくれます。

**アプリが使えない場合の代替タスク（紙のみ）**

Grace 役を自分で想像し、道を尋ねるやり取りを6〜8往復、英語で書いてみましょう。**Could you / Would you**、命令文（imperative）、場所の前置詞を必ず1回以上使ってください。

```
You:
Grace:
You:
Grace:
You:
Grace:
```
