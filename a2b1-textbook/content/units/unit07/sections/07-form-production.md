今度は自分で文を作ります。（　）に **would like** か **could I have** の正しい形を書きましょう。

1. A: Are you ready to order?　B: Yes, I ( 　　　 ) the pasta, please. → **'d like / would like**
2. A: ( 　　　 ) a look at the menu, please? → **Could I have**
3. A: ( 　　　 ) some coffee with your meal?　B: Yes, please. → **Would you like**
4. A: ( 　　　 ) the bill, please?　B: Sure, one moment. → **Could we have**
5. A: What ( 　　　 ) for dessert?　B: I ( 　　　 ) the ice cream, please. → **would you like / 'd like**

### 頼んでみよう

**Could I have 〜, please?** または **Could you 〜, please?** を使って、次の場面で丁寧に頼む文を書きましょう。

6. デザートのメニューが見たいとき：_____________________________________________
7. フォークをもう一本ほしいとき：_____________________________________________
8. 店員におすすめの料理を聞きたいとき：_____________________________________________

### 短い自由作文

レストランで注文する場面を、2〜3文で書いてみましょう。**I'd like** と **Could I have** を少なくとも1回ずつ使ってください。
