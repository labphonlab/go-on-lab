**紙面での準備（アプリを使う前に）**

1. あなたがカフェで注文したい飲み物と食べ物を1つずつ考えましょう（例：コーヒーとサンドイッチ）。
2. Nora（AI の店員）は、あなたが知らない情報（本日のおすすめ・売り切れの商品）を持っています。質問して聞き出しましょう。
3. 次の表現を最低1回ずつ使うことを目標にします。

   - **I'd like 〜, please.** で注文する
   - **Could I have 〜, please?** で丁寧に頼む
   - メニューについて質問する（例：*What's today's special? Do you have any sandwiches?*）
   - 頼んだものが売り切れだったとき、丁寧に別のものを選ぶ

**アプリでのロールプレイ**

QR コード（このユニットの先頭）または `learn.goonresearch.jp/u/7` からアプリを開き、"Main Task: Roleplay" を選んでください。Nora と英語でやり取りしながら、注文を完成させましょう。会話が終わると、AI が達成度を確認してくれます。

**アプリが使えない場合の代替タスク（紙のみ）**

店員役を自分で想像し、カフェでの注文のやり取りを6〜8往復、英語で書いてみましょう。**I'd like**、**Could I have** を必ず使ってください。

```
You:
Barista:
You:
Barista:
You:
Barista:
```
