まずは「意味を正しく聞き分ける」練習です。まだ自分では書きません。文をよく読んで、意味を選びましょう。

### タスク A（アドバイスか、必要かを聞き分ける）

それぞれの文が (a) 「アドバイス（した方がいい／しない方がいい）」と (b) 「必要・義務（しなければならない）」のどちらを表しているか、○をつけましょう。

1. You **should** drink a lot of water when you have a fever.
   → ( **a. アドバイス** ／ b. 必要・義務 )

2. I **have to** take this medicine three times a day. The doctor said so.
   → ( a. アドバイス ／ **b. 必要・義務** )

3. You **shouldn't** exercise today. Just rest.
   → ( **a. アドバイス** ／ b. 必要・義務 )

4. Jake **has to** go to the pharmacy before it closes.
   → ( a. アドバイス ／ **b. 必要・義務** )

5. You **should** ask the pharmacist if you're not sure about the medicine.
   → ( **a. アドバイス** ／ b. 必要・義務 )

### タスク B（"shouldn't" と "don't have to" を聞き分ける）

それぞれの文が「しない方がいい（アドバイス）」か「する必要はない（義務がない）」か、印をつけましょう。

6. You **don't have to** see a doctor for a small cold.
   → ( しない方がいい ／ **する必要はない** )

7. You **shouldn't** skip meals when you're taking painkillers.
   → ( **しない方がいい** ／ する必要はない )

8. You **don't have to** make an appointment. Just walk in.
   → ( しない方がいい ／ **する必要はない** )
