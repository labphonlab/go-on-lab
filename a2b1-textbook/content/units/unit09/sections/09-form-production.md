今度は自分で文を作ります。（　）に **should**、**shouldn't**、**have to**、**don't have to** のうち正しいものを書きましょう。

1. A: I have a stomachache.　B: You ( 　　　 ) eat something light, like rice. → **should**
2. You have a bad cough. You ( 　　　 ) smoke, and you ( 　　　 ) get some rest. → **shouldn't / should**
3. A: Do I ( 　　　 ) go to the clinic for a small headache?　B: No, you ( 　　　 ). Just take a painkiller. → **have to / don't have to**
4. Jake ( 　　　 ) go to school tomorrow if he still has a fever. → **shouldn't**
5. A: I'm allergic to some medicine.　B: Then you ( 　　　 ) tell the pharmacist before you buy anything. → **should**

### アドバイスしてみよう

**should** または **shouldn't** を使って、次の場面でアドバイスする文を書きましょう。

6. 友だちがめまい（dizzy）がすると言っているとき：_____________________________________________
7. 友だちがのどの痛みで、今日は運動の予定があるとき：_____________________________________________
8. 友だちが熱があるのに、パーティーに行きたがっているとき：_____________________________________________

### 短い自由作文

体調が悪い友だちに送るメッセージを、2〜3文で書いてみましょう。**shouldn't** を少なくとも1回、**have to** か **don't have to** を少なくとも1回使ってください。
