それぞれの文が、どの文法を主に使っているか選びましょう。

1. Turn right at the next corner.
   → ( **命令文（道案内）** ／ Would like ／ 関係代名詞 ／ should )
2. Would you like some more coffee?
   → ( 命令文 ／ **Would like** ／ 関係代名詞 ／ should )
3. The man who called you yesterday is my neighbor.
   → ( 命令文 ／ Would like ／ **関係代名詞** ／ should )
4. You shouldn't eat that if you have a stomachache.
   → ( 命令文 ／ Would like ／ 関係代名詞 ／ **should** )
5. Could you show me the way to the library?
   → ( **丁寧な依頼（Could you）** ／ Would like ／ 関係代名詞 ／ should )

次の文を読んで、質問に答えましょう。

6. "You should see a doctor, but you don't have to stay in bed all day." この人は、病院に行くことを（ **勧めている** ／ 止めている ）。一日中寝ていることは（ しなければならない ／ **しなくてもよい** ）。
7. "The restaurant that we visited last week was the one which had the best pizza." 二人が先週行ったレストランは、一番おいしいピザがある店（ **と同じ** ／ とは違う ）。
