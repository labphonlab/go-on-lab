正しい形を（　）に書きましょう。

1. A: How do I get to the station? B: ( 　　　 ) straight and turn left. → **Go**
2. ( 　　　 ) you like something to drink? → **Would**
3. ( 　　　 ) I have the bill, please? → **Could**
4. This is the shop ( 　　　 ) sells the best bread in town. → **that / which**
5. You ( 　　　 ) rest if you have a fever, but you don't have to stay home all week. → **should**

次の文章の空らんを埋めて、知らない街での一日を書いてみましょう（命令文/丁寧な依頼、Would like/Could I have、関係代名詞、should/shouldn't を少なくとも1回ずつ使ってください）。

```
Excuse me, could you ______________________________?
I'd like ______________________________, please.
I met someone who ______________________________.
If you feel sick, you should ______________________________.
```
