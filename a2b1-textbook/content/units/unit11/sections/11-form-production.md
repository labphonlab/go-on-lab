今度は自分で文を作ります。（　）に動詞の正しい形（**was/were + -ing** か、普通の過去形）を書きましょう。

1. I ( 　　　 / watch ) a movie when my neighbor knocked on the door. → **was watching**
2. The alarm ( 　　　 / go off ) while everyone was talking. → **went off**
3. It ( 　　　 / rain ) when the accident happened outside the shop. → **was raining**
4. Mia ( 　　　 / sit ) on the sofa, eating popcorn, when she heard the noise. → **was sitting**
5. A police car and an ambulance ( 　　　 / arrive ) while the neighbors were still talking about the crash. → **arrived**

### while / when を使ってみよう

次の2つの状況を、**while** または **when** を使って1つの文にしましょう。

6. あなたはお風呂に入っていた。その時、友だちから電話がかかってきた。：_____________________________________________
7. 兄（弟）はテレビゲームをしていた。その時、突然停電した。：_____________________________________________
8. あなたは公園を歩いていた。その時、犬が急に走ってきた。：_____________________________________________

### 短い自由作文

先週、あなたの身に起きた「ちょっとした出来事」を、背景（**was/were + -ing**）と出来事（普通の過去形）を組み合わせて、3〜4文で書いてみましょう。**while** または **when** を少なくとも1回使ってください。
