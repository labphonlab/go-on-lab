まずは「意味を正しく聞き分ける」練習です。まだ自分では書きません。文をよく読んで、意味を選びましょう。

### タスク A（条件と結果を選ぶ）

それぞれの文を読んで、正しい組み合わせに○をつけましょう。

1. If it rains tomorrow, we will stay home.
   → 明日雨が降ったら、（ **家にいる** ／ 出かける ）。

2. If I have enough money, I'll buy a new bike.
   → お金が十分にあったら、（ 自転車を借りる ／ **自転車を買う** ）。

3. If the traffic is bad, we'll be late for the meeting.
   → 交通状況が悪かったら、（ **会議に遅れる** ／ 会議を休む ）。

4. If Jack finishes his report early, he'll have free time this weekend.
   → Jack がレポートを早く終えたら、（ **週末に自由な時間ができる** ／ 週末も残業する ）。

### タスク B（if か when かを聞き分ける）

それぞれの文が「まだ起こるかわからないこと（if）」か「必ず起こること（when）」のどちらを表しているか、○をつけましょう。

5. **If** it's sunny on Sunday, we'll go hiking.
   → ( **まだわからない（if）** ／ 必ず起こる（when） )

6. **When** I finish work today, I'll call you.
   → ( まだわからない（if） ／ **必ず起こる（when）** )　※仕事を終えることは決まっている

7. **If** the shop has a discount, I'll buy two.
   → ( **まだわからない（if）** ／ 必ず起こる（when） )
