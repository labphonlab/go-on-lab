今度は自分で文を作ります。（　）に **if の節（現在形）** か **will の節** の正しい形を書きましょう。

1. If it ( 　　　 / rain ) tomorrow, we ( 　　　 ) stay home. → **rains** / **will**
2. If I ( 　　　 / have ) enough time, I ( 　　　 ) go hiking. → **have** / **'ll**
3. If the weather ( 　　　 / be ) bad, the picnic ( 　　　 ) probably be cancelled. → **is** / **will**
4. If Jack ( 　　　 / not finish ) his report, he ( 　　　 ) have to work overtime. → **doesn't finish** / **'ll**
5. If there ( 　　　 / be ) a traffic jam, we ( 　　　 ) be late. → **is** / **'ll**

### if か when かを選ぼう

（　）に **if** か **when** の正しい方を書きましょう。

6. ( 　　　 ) I get home tonight, I'll cook dinner. （必ず家に帰る） → **When**
7. ( 　　　 ) it's sunny this weekend, we'll go to the mountain. （晴れるかわからない） → **If**
8. ( 　　　 ) the report is ready, I'll send it to you. （報告書は完成する予定） → **When**

### 自分で文を作ろう

次の場面で、"if + 現在形, ... will 〜" の文を書きましょう。

9. 天気がよかったら、外で何をしますか：_____________________________________________
10. お金が十分にあったら、何を買いますか：_____________________________________________
11. 早く仕事（または宿題）を終えたら、何をしますか：_____________________________________________

### 短い自由作文

今度の週末の予定について、「もし〜なら」を使って2〜3文で書いてみましょう。**if + 現在形** と **will** を少なくとも1回ずつ使ってください。
