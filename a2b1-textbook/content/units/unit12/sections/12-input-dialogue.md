音声を聞きながら、Yuki と Jack が週末の予定について話す様子を読みましょう。まだ何も決まっていません。天気と仕事の状況によって、予定が変わりそうです。

**Yuki:** Hi Jack! Do you want to go hiking this weekend?

**Jack:** That sounds great! But I need to check the weather forecast first.

**Yuki:** Good idea. If it's sunny on Saturday, we can go to the mountain trail.

**Jack:** And if the weather is bad, what will we do?

**Yuki:** If the weather is bad, we'll stay home and watch a movie instead.

**Jack:** Okay. I also have a big report for work, and the deadline is Friday. If I finish it today, I'll have free time this weekend.

**Yuki:** And if you don't finish it?

**Jack:** If I don't finish it, I'll have to work overtime on Saturday morning.

**Yuki:** Try to finish early! Let's check the forecast now.

**Jack:** Okay... the forecast is cloudy in the morning, but it will clear up in the afternoon.

**Yuki:** Great! If the weather is nice, we won't need to change our plan.

**Jack:** True. But if there's a traffic jam on the way, we could be late.

**Yuki:** If we leave early, we won't get stuck in traffic.

**Jack:** You're right. If we leave at eight, we'll arrive before ten.

**Yuki:** Sounds like a plan! I'll bring a picnic, and you bring the water.

**Jack:** Okay. If we have enough time, we can go to the mountain too.

**Yuki:** Great! I can't wait.

---

### 内容チェック

1. Yuki and Jack are going to check the ( weather forecast / bus schedule ) first.
2. If it's sunny, they are going to go to the ( mountain trail / beach ).
3. Jack has a report, and the deadline is ( Thursday / Friday ).
