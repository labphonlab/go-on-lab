まずは「正しい語順を見分ける」練習です。まだ自分では書きません。それぞれ、自然な間接疑問文はどちらか選びましょう。

### タスク A（語順を選ぶ）

1. Could you tell me ( what time is it / **what time it is** )?
2. Do you know ( **if there is a pool** / is there a pool )?
3. Could you tell me ( where is the entrance / **where the entrance is** )?
4. Do you know ( **whether I need an appointment** / whether do I need an appointment )?
5. Could you tell me ( how much does the membership cost / **how much the membership is** )?
6. Do you know ( **if the class is popular** / is the class popular )?

### タスク B（丁寧さを聞き分ける）

それぞれの文が「丁寧・間接的」か「直接的」か、印をつけましょう（正解は一つに決まらない場合もあります。話す相手や場面を考えて選んでください）。

7. **Where is the changing room?**　→ ( 丁寧・間接的 ／ **直接的** )
8. **Could you tell me where the changing room is?**　→ ( **丁寧・間接的** ／ 直接的 )
9. **Is there a discount for students?**　→ ( 丁寧・間接的 ／ **直接的** )
10. **Do you know if there's a discount for students?**　→ ( **丁寧・間接的** ／ 直接的 )
