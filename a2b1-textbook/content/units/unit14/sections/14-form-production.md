今度は自分で文を作ります。（　）に **is/are** または **was/were** と、動詞の正しい過去分詞を書きましょう。

1. This bag ( 　　　 / make ) in Vietnam. → **is made**
2. These shoes ( 　　　 / design ) by a famous company. → **are designed**
3. The Eiffel Tower ( 　　　 / build ) in 1889. → **was built**
4. Rice ( 　　　 / grow ) in many parts of Japan. → **is grown**
5. This recipe ( 　　　 / invent ) by my mother, many years ago. → **was invented**
6. Chocolate ( 　　　 / produce ) in factories all over the world. → **is produced**

### 能動態から受動態へ

次の能動態の文を、受動態の文に書きかえましょう（by 〜 をつけてもつけなくても構いません）。
