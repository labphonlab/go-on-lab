正しい形を（　）に書きましょう。

1. This cheese ( 　　　 ) (make) in France. → **is made**
2. While I ( 　　　 ) (walk) to the station, it started to rain. → **was walking**
3. ( 　　　 ) you tell me how to get to the museum? → **Could**
4. If I have time this weekend, I ( 　　　 ) (visit) my grandmother. → **will visit**
5. This building ( 　　　 ) (build) over a hundred years ago. → **was built**

次の文章の空らんを埋めて、自分自身について書いてみましょう（過去進行形＋過去形、条件文、間接疑問、受動態を少なくとも1回ずつ使ってください）。

```
While I was ______________________________, something happened.
If I have free time next week, I ______________________________.
Could you tell me ______________________________?
Something I use every day, like my phone, is made ______________________________.
```
