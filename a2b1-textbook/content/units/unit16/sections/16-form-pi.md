まずは「どちらの形が正しいか」を見分ける練習です。まだ自分では書きません。文をよく読んで、正しい方を選びましょう。

### タスク A（正しい形を選ぶ）

それぞれの文で、正しい方に○をつけましょう。

1. I want ( to travel / traveling ) to Canada someday.
   → ( **to travel** ／ traveling )

2. My sister enjoys ( to cook / cooking ) for her family.
   → ( to cook ／ **cooking** )

3. We decided ( to move / moving ) to a bigger city next year.
   → ( **to move** ／ moving )

4. He avoids ( to eat / eating ) fast food when he can.
   → ( to eat ／ **eating** )

5. They plan ( to open / opening ) a new shop this summer.
   → ( **to open** ／ opening )

6. I hope ( to see / seeing ) you again soon.
   → ( **to see** ／ seeing )

7. She promised ( to help / helping ) me with my homework.
   → ( **to help** ／ helping )

8. Do you keep ( to practice / practicing ) English every day?
   → ( to practice ／ **practicing** )

### タスク B（動詞のグループ分け）

次の動詞を、「**to + 動詞の原形**」をとるグループと「**動詞 + -ing**」をとるグループに分けて、下の表に書きましょう。

want / enjoy / decide / avoid / hope / keep / plan / promise / expect / consider / quit / imagine

| to + 動詞の原形 | 動詞 + -ing |
|---|---|
| want, hope, decide, plan, promise, expect | enjoy, avoid, keep, consider, quit, imagine |

### タスク C（自分ならどう考えるか）

次の文を読んで、内容が自分に当てはまるかどうか考えてみましょう（正解は一つではありません）。

9. "I hope to travel abroad next year." → あなたも来年、海外旅行を望んでいますか。( はい ／ いいえ ／ わからない )
10. "I avoid spending money on things I don't need." → あなたも同じようにしていますか。( はい ／ いいえ ／ わからない )
