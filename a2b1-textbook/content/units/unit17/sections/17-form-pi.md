まずは「意味を正しく聞き分ける」練習です。まだ自分では書きません。文をよく読んで、意味を選びましょう。

### タスク A（賛成か反対かを聞き分ける）

それぞれの応答が、相手の意見に「賛成」か「反対」かのどちらを表しているか、○をつけましょう。

1. A: I think working from home is better.　B: **I agree.**
   → ( **賛成** ／ 反対 )

2. A: In my opinion, city life is more convenient.　B: **I don't think so.**
   → ( 賛成 ／ **反対** )

3. A: I love spicy food.　B: **So do I.**
   → ( **賛成（同意）** ／ 反対 )

4. A: I don't really enjoy big parties.　B: **Neither do I.**
   → ( **賛成（同意）** ／ 反対 )

5. A: Dogs are more loyal than cats.　B: **I disagree.**
   → ( 賛成 ／ **反対** )

### タスク B（So か Neither かを聞き分ける）

相手の文が肯定文か否定文かに注目して、正しい応答を選びましょう（正解は一つに決まらない場合もあります）。

6. A: I can speak a little French.　B: ( **So can I.** ／ Neither can I. )
7. A: I don't like getting up early.　B: ( So do I. ／ **Neither do I.** )
8. A: I'm not sure about this plan.　B: ( So am I. ／ **Neither am I.** )
9. A: I really want a pet.　B: ( **So do I.** ／ Neither do I. )

### タスク C（自分ならどう思うか）

次の意見について、あなたは賛成ですか、反対ですか。理由も考えてみましょう（正解は一つではありません）。
