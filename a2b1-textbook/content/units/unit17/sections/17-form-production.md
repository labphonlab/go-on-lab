今度は自分で文を作ります。（　）に **So** か **Neither** の正しい形を書きましょう。

1. A: I love animals.　B: ( 　　　 ) do I. → **So**
2. A: I don't want a big dog.　B: ( 　　　 ) do I. → **Neither**
3. A: I'm not convinced about this plan.　B: ( 　　　 ) am I. → **Neither**
4. A: I can understand her point of view.　B: ( 　　　 ) can I. → **So**
5. A: I don't think that's fair.　B: ( 　　　 ) do I. → **Neither**

### 賛成・反対を伝えてみよう

次の意見に対して、**I agree** または **I disagree** を使って、あなたの考えを書きましょう。理由も1文添えてください。
