今度は自分で文を作ります。（　）に動詞の正しい形（過去形 または 過去進行形）を書きましょう。

1. I ( 　　　 / wait ) for the bus when I ( 　　　 / notice ) I had no money. → **was waiting / noticed**
2. While Maya ( 　　　 / sit ) on the train, the man ( 　　　 / start ) talking to her. → **was sitting / started**
3. I ( 　　　 / walk ) home when it ( 　　　 / begin ) to rain. → **was walking / began**
4. He ( 　　　 / apologize ) while everyone ( 　　　 / watch ). → **apologized / was watching**

### 間接話法に書きかえよう

直接話法の文を、間接話法（**said** または **told me**）を使って書きかえましょう。

5. "I'm tired," Ben said. → Ben said ( 　　　　　　　　　　　　　　　 ). → **(that) he was tired**
6. "The museum is closed today," Aya said. → Aya said ( 　　　　　　　　　　　　　　　 ). → **(that) the museum was closed today**
7. "I already finished my homework," he told me. → He told me ( 　　　　　　　　　　　　　　　 ). → **(that) he had already finished his homework**

### 短い自由作文

最近あったちょっとした出来事（電車に乗り遅れた、道に迷った、驚いたこと、など）を、3〜4文で書いてみましょう。**過去進行形**を少なくとも1回、**said** または **told me** を少なくとも1回使ってください。
