まずは「意味を正しく聞き分ける」練習です。まだ自分では書きません。文をよく読んで、意味を選びましょう。

### タスク A（本当にそうなのか、仮の話なのか）

それぞれの文が (a) 「実際に起きたこと」と (b) 「実際には起きていない、仮の話」のどちらを表しているか、○をつけましょう。

1. If I lost my passport, I would go to the embassy.
   → ( a. 実際に起きたこと ／ **b. 仮の話** )

2. I lost my passport, so I went to the embassy.
   → ( **a. 実際に起きたこと** ／ b. 仮の話 )

3. If I missed my flight, I would ask the airline for help.
   → ( a. 実際に起きたこと ／ **b. 仮の話** )

4. I missed my flight, so I asked the airline for help.
   → ( **a. 実際に起きたこと** ／ b. 仮の話 )

5. If I were you, I would buy travel insurance.
   → ( a. 実際に起きたこと ／ **b. 仮の話** )

### タスク B（後悔しているのは、したことか、しなかったことか）

それぞれの文で、話し手が後悔しているのは (a) 「したこと」と (b) 「しなかったこと」のどちらか、○をつけましょう。

6. I should have checked the gate number before I left.
   → ( a. したこと ／ **b. しなかったこと** )

7. I should not have put my passport in my suitcase.
   → ( **a. したこと** ／ b. しなかったこと )

8. Jack should have packed some clothes in his carry-on bag.
   → ( a. したこと ／ **b. しなかったこと** )

9. Jack should not have booked such a short connection.
   → ( **a. したこと** ／ b. しなかったこと )
