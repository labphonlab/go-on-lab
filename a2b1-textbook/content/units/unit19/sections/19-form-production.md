今度は自分で文を作ります。（　）に正しい形を書きましょう。

### if + 過去形, would 〜

1. If I ( 　　　 / lose ) my wallet, I ( 　　　 / call ) the police. → **lost / would call**
2. If the flight ( 　　　 / be ) cancelled, what ( 　　　 / you / do )? → **were / would you do**
3. If I ( 　　　 / miss ) my connection, I ( 　　　 / ask ) the airline staff for help. → **missed / would ask**
4. If I ( 　　　 / be ) you, I ( 　　　 / buy ) travel insurance before the trip. → **were / would buy**

### should have / should not have

5. I missed the gate announcement, so I ( 　　　 / check ) my flight time more carefully. → **should have checked**
6. Jack put his passport in his suitcase, so he ( 　　　 / put ) it in his bag instead. → **should not have put**
7. We didn't have travel insurance, so we ( 　　　 / buy ) it before the trip. → **should have bought**
8. I complained to the airline too late. I ( 　　　 / complain ) at the airport. → **should have complained**

### 自分の文を作ろう

9. あなたが空港でパスポートをなくしたら、どうしますか。**if + 過去形, would 〜** を使って書きましょう。

   _____________________________________________

10. 過去に旅行で失敗した経験（自分の経験でも、想像でもよい）を1つ考え、**should have** または **should not have** を使って、後悔の気持ちを書きましょう。

    _____________________________________________

### 短い自由作文

旅行中に起こりうるトラブルを1つ選び、(1) **if + 過去形, would 〜** を使って、そのときの解決策を書き、(2) **should have / should not have** を使って、それを防ぐために何ができたかを書いてみましょう（2〜3文）。
