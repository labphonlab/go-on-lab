対話をもう一度見て、太字の部分に注目しましょう。

> Emi: **If I lost** my suitcase like that, **I would be** so upset.
> Jack: Now I think **I should have packed** some clothes in my carry-on bag.
> Jack: Yeah, **I should not have put** everything in one suitcase.
> Jack: But **if I lost** my passport, **I would go** to the embassy immediately.
> Emi: **If I were** you, **I would** also buy travel insurance next time.

### 日英対照

| 英語の形 | 使うとき | 日本語での近い感覚 |
|---|---|---|
| **If + 主語 + 過去形 〜, 主語 + would + 動詞の原形 〜** | 今・未来について「（実際にはそうではないけれど）もし〜だったら」という仮の話をする | 「もし〜だったら、〜するだろう」 |
| **If I were 〜** | if 文の中で be動詞を使うとき、主語が何でも were を使うことが多い | 「もし〜だったら」 |
| **should have + 過去分詞** | 過去にしなかったことを、今振り返って「〜すればよかった」と後悔する | 「〜すればよかった」 |
| **should not have + 過去分詞** | 過去にしてしまったことを、今振り返って「〜しなければよかった」と後悔する | 「〜しなければよかった」 |

### 気づきポイント

1. Emi の "**If I lost** my suitcase, **I would be** so upset." は、実際には Emi のスーツケースはなくなっていません。「もし（自分が）そうなったら」という仮の話をしているので、if の中は過去形（lost）、後ろの文は **would** を使います。
2. Jack の "**I should have packed** some clothes in my carry-on bag." は、実際には手荷物に服を入れませんでした。過去のことについて「〜すればよかった」と後悔しているので、**should have + 過去分詞** を使います。
3. 反対に、してしまったことを後悔するときは "**I should not have put** everything in one suitcase." のように **should not have + 過去分詞** を使います。
4. **if + 過去形 〜, would 〜** の文で、be動詞を使うときは、主語が I や he、she であっても **were** を使うのが自然です（"**If I were** you, ..." のように）。

**確認問題**：対話の中から、"if + 過去形 〜, would 〜" または "should have / should not have" が使われている文をもう一つ探して、下に書いてみましょう。
