正しい形を（　）に書きましょう。

1. She hopes ( 　　　 ) (become) a doctor. → **to become**
2. He enjoys ( 　　　 ) (cook) for his friends. → **cooking**
3. "I think this book is great." "So ( 　　　 ) I." → **do**
4. If I ( 　　　 ) (have) more free time, I would learn a new language. → **had**
5. I ( 　　　 ) (should / study) more before the exam. → **should have studied**

最後の自由作文です。この本で学んだ文法を使って、これからの自分について書いてみましょう（不定詞/動名詞、意見の表現、第2条件文、should have のうち少なくとも2つを使ってください）。

```
In the future, I want ______________________________.
In my opinion, ______________________________.
If I had more time to study English, I ______________________________.
Looking back at this book, I think I should have ______________________________.
```
