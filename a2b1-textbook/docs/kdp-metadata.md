# KDP 出版ガイド

このドキュメントは、`a2b1-textbook` を Amazon KDP（Kindle Direct Publishing）で
紙版（ペーパーバック）と電子版（Kindle）として出版するための、メタデータ案と
手順チェックリストです。

**重要**: このリポジトリのスクリプトは原稿ファイル（印刷用 PDF のもとになる
`.typ`、Kindle 用 `.epub`、表紙 PNG）を生成するところまでを行います。KDP
アカウントでのアップロード・銀行口座/税務情報の登録・実際の「出版」操作は
発行者（あなた）が KDP の管理画面（kdp.amazon.com）で行う必要があります。

### 紹介文（商品説明）案

> CEFR A2（英検準2級〜2級・TOEIC 400〜550）から B1 へ。教師なしで進められる、
> 4技能（聞く・読む・話す・書く）総合英語トレーニングです。
>
> 全20ユニットは、第二言語習得研究（SLA）の知見に基づいた7ステップ構成
> （Warm-up → Input → Noticing → Language Focus → Main Task → Fluency →
> Reflection）で統一。各ユニットの語彙は「すでに知っている語＋そのユニット
> の新出語」で98%以上をカバーするよう厳密に設計されているため、辞書なしで
> も無理なく読み進められます。
>
> 紙面には各所にQRコード・短縮URLが印刷されており、無料のウェブアプリ
> （インストール不要）でリスニング音声・シャドーイング練習・AIとの対話
> ロールプレイ・語彙の間隔反復（SRS）復習に接続できます。
>
> こんな方におすすめです：
> - 英検準2級・2級、TOEIC 400〜550点台から次のレベルを目指す方
> - 独学で英語をやり直したい社会人・学生
> - 「読む」「聞く」だけでなく「話す」「書く」もバランスよく鍛えたい方

## 2. 紙版（ペーパーバック）

- **トリムサイズ**: 7 in × 10 in（`content/book_meta.yaml` の `trim_size`）。ワークブック系で一般的なサイズです。
- **原稿生成**: `python3 scripts/build_pdf.py --full-book --typ-only` → `build/pdf/full-book.typ`
- **PDF コンパイル**: [Typst](https://github.com/typst/typst#installation) をインストールし、
  `typst compile build/pdf/full-book.typ build/pdf/full-book.pdf`（または `--typ-only` を外して
  `build_pdf.py --full-book` を実行すれば同時にPDFまで生成されます）。
  **実際にコンパイル済み・目視確認済み**: 全20ユニット込みで**199ページ**。タイトルページ・
  自動生成目次（Typst `#outline()`）・全ユニットの対話/表組み・QRコードブロック・巻末語彙索引・
  Can-do チェックリスト、いずれも正しくレンダリングされることを確認しています
  （日本語フォントは `Noto Sans CJK JP` を指定していますが、未インストール環境では Typst が
  自動的に他のCJKフォントにフォールバックします。最終入稿前に `Noto Sans CJK JP` 等の
  高品質な日本語フォントをインストールした環境で再コンパイルすることを推奨します）。
- **のど（inside）余白の再確認が必須**: `margin_inside_in` は暫定値（0.875in）です。
  上記の実ページ数（199ページ）を踏まえ、KDP の「Print margin requirements」ページか、KDP
  アップロード画面のプレビューア（Previewer）で実際の推奨値を確認し、
  `content/book_meta.yaml` を更新してから再ビルドしてください。
- **表紙（フルラップ）**: `python3 scripts/build_paperback_cover.py --pages 199` で
  背表紙込みのフルラップPDF（`build/cover/paperback-wrap-cover.pdf`）を生成できます
  （表紙・背表紙・裏表紙ブラーブ・KDPバーコード用の余白ボックスを含む、ブリード0.125in込み）。
  背表紙幅は `page_count × 0.0025in` という一般的な目安値で計算した**推定値**（199ページで
  約0.5in）です。**KDP公式のカバー計算ツールで実際の推奨値を必ず確認し、異なる場合は
  再生成してください**。これも Kindle 版カバー（`build_cover.py`）と同様、プロ用の
  プレースホルダーデザインです。
- **色**: 本文は白黒（モノクロ）印刷を想定した設計です（強調はボールド/罫線で行い、
  色に依存していません）。カラー印刷にすると単価が大きく上がるため、モノクロ推奨。

## 3. 電子版（Kindle）

- **原稿生成**: `python3 scripts/build_epub.py` → `build/epub/book.epub`
- KDP は EPUB を直接アップロードできます（Kindle Create は不要）。アップロード後、
  KDP 側のオンラインプレビューアで各ユニットの表示・QRセクションのリンクが
  「アプリで続ける」というテキストリンクとして機能することを確認してください。
- **表紙**: `build/cover/ebook-cover.png`（1600×2560px）。これはプレースホルダー
  デザインです。正式リリース前にプロのデザインに差し替えることを推奨します。
- 電子版に ISBN は不要です（KDP が ASIN を自動採番）。

## 5. 既知の残課題

- **フォント**: この検証環境には `Noto Sans CJK JP` がなく、Typst は自動的に別のCJK
  フォント（IPAGothic）にフォールバックしています。見た目は正常でしたが、印刷入稿前に
  本番想定フォントで再コンパイルし、字形を確認してください。
- **背表紙幅**: `build_paperback_cover.py` の 0.0025in/ページという係数は一般的な目安値で、
  KDP公式の値ではありません。KDPのアップロード画面またはカバー計算ツールで必ず確認してください。
- **表紙デザイン**: 電子版・紙版とも、現状はプログラムで生成したプレースホルダーです
  （タイポグラフィのみ、写真・イラストなし）。正式リリース前にプロのデザインに差し替えることを
  推奨します。
