# KDP 出版ガイド

このドキュメントは、`a2b1-textbook` を Amazon KDP（Kindle Direct Publishing）で
紙版（ペーパーバック）と電子版（Kindle）として出版するための、メタデータ案と
手順チェックリストです。

**重要**: このリポジトリのスクリプトは原稿ファイル（印刷用 PDF のもとになる
`.typ`、Kindle 用 `.epub`、表紙 PNG）を生成するところまでを行います。KDP
アカウントでのアップロード・銀行口座/税務情報の登録・実際の「出版」操作は
発行者（あなた）が KDP の管理画面（kdp.amazon.com）で行う必要があります。

### 紹介文（商品説明）案

> CEFR A2（英検準2級〜2級・TOEIC 400〜550）から B1 へ。教師なしで進められる、
> 4技能（聞く・読む・話す・書く）総合英語トレーニングです。
>
> 全20ユニットは、第二言語習得研究（SLA）の知見に基づいた7ステップ構成
> （Warm-up → Input → Noticing → Language Focus → Main Task → Fluency →
> Reflection）で統一。各ユニットの語彙は「すでに知っている語＋そのユニット
> の新出語」で98%以上をカバーするよう厳密に設計されているため、辞書なしで
> も無理なく読み進められます。
>
> 紙面には各所にQRコード・短縮URLが印刷されており、無料のウェブアプリ
> （インストール不要）でリスニング音声・シャドーイング練習・AIとの対話
> ロールプレイ・語彙の間隔反復（SRS）復習に接続できます。
>
> こんな方におすすめです：
> - 英検準2級・2級、TOEIC 400〜550点台から次のレベルを目指す方
> - 独学で英語をやり直したい社会人・学生
> - 「読む」「聞く」だけでなく「話す」「書く」もバランスよく鍛えたい方

（※ 上記は初期案です。実際の登録前に、発行者の言葉で調整してください。）

## 2. 紙版（ペーパーバック）

- **トリムサイズ**: 7 in × 10 in（`content/book_meta.yaml` の `trim_size`）。ワークブック系で一般的なサイズです。
- **原稿生成**: `python3 scripts/build_pdf.py --full-book --typ-only` → `build/pdf/full-book.typ`
- **PDF コンパイル**: [Typst](https://github.com/typst/typst#installation) をインストールし、
  `typst compile build/pdf/full-book.typ build/pdf/full-book.pdf`
  （このリポジトリの実行環境には Typst が入っていないため未検証。**PDF を開いて
  目次・改ページ・QRコードの見た目を必ず確認してください**）
- **のど（inside）余白の再確認が必須**: `margin_inside_in` は暫定値（0.875in）です。
  最終ページ数が確定したら、KDP の「[Print margin requirements]」ページか、KDP
  アップロード画面のプレビューア（Previewer）で実際の推奨値を確認し、
  `content/book_meta.yaml` を更新してから再ビルドしてください。ページ数が多いほど
  のど側の余白は広く必要になります。
- **表紙（フルラップ）**: このリポジトリは Kindle 用の単体カバー画像
  （`build/cover/ebook-cover.png`、`scripts/build_cover.py` で生成）しか作っていません。
  ペーパーバックは「表紙＋背表紙＋裏表紙」が1枚につながったフルラップPDFが必要で、
  背表紙の幅は最終ページ数から KDP 側で自動計算されます。KDP の
  [Cover Creator] を使うか、`ebook-cover.png` のデザインを踏襲してデザイナーに
  フルラップを依頼してください。
- **色**: 本文は白黒（モノクロ）印刷を想定した設計です（強調はボールド/罫線で行い、
  色に依存していません）。カラー印刷にすると単価が大きく上がるため、モノクロ推奨。

## 3. 電子版（Kindle）

- **原稿生成**: `python3 scripts/build_epub.py` → `build/epub/book.epub`
- KDP は EPUB を直接アップロードできます（Kindle Create は不要）。アップロード後、
  KDP 側のオンラインプレビューアで各ユニットの表示・QRセクションのリンクが
  「アプリで続ける」というテキストリンクとして機能することを確認してください。
- **表紙**: `build/cover/ebook-cover.png`（1600×2560px）。これはプレースホルダー
  デザインです。正式リリース前にプロのデザインに差し替えることを推奨します。
- 電子版に ISBN は不要です（KDP が ASIN を自動採番）。

## 4. 出版前チェックリスト（発行者が行う作業）

- [ ] `content/book_meta.yaml` の全項目を確認・確定する（特に `contact_email`）
- [ ] Unit 2〜20 の内容を最終確認する（本リポジトリで執筆中。進捗は README 参照）
- [ ] Typst をインストールし、`build_pdf.py --full-book` で実際に PDF をコンパイル、
      印刷イメージを目視確認する
- [ ] のど余白を最終ページ数に合わせて再確認・調整する
- [ ] ペーパーバックのフルラップ表紙（表紙＋背表紙＋裏表紙）をデザインする
- [ ] `build_epub.py` の出力を Kindle Previewer（Amazon 提供の無料デスクトップアプリ）
      で確認する
- [ ] KDP アカウントを作成し、出版社情報・銀行口座・税務情報（W-8BEN 等）を登録する
- [ ] KDP で新しいタイトルを作成し、上記メタデータを入力、原稿・表紙をアップロードする
- [ ] 価格を設定する（紙版は印刷コストがKDPにより自動計算され、そこに利益分を上乗せする方式）
- [ ] プレビューで最終確認し、実際に「出版」を実行する（この最後のクリックは発行者本人が行う）

## 5. 既知の未検証事項

このサンドボックス環境には `typst` バイナリがなく、生成した `.typ` を実際に
コンパイルしたことがありません。Typst の構文（特に `#set page(margin: (inside:
..., outside: ...))` のようなミラーマージン記法、`#outline()` の挙動、
ページ番号のローマ数字→算用数字への切り替え）は仕様に基づいて実装していますが、
**実際のコンパイルで初めて構文エラーが見つかる可能性があります**。Typst 導入後、
最初のビルドで出たエラーはこの `build_pdf.py` 側の Typst 生成コードの修正で
対応できるはずです。
