# Cross-inventory inconsistency analysis

_Generated by `scripts/02_inconsistency_analysis.py` from PHOIBLE 2.0 joined with Glottolog._

> **Why this matters.** Existing phoneme-inventory databases routinely *merge* multiple descriptions of the same language into a single inventory. Doing so silently discards genuine disagreement between sources (Simpson 1999; Hammarström et al. 2023). The figures below quantify that disagreement — the data this project refuses to hide.
