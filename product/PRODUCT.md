# Perception Lab — 音声知覚実験プラットフォーム

> 心理測定関数の取得を、コードを書かずに。
> スマホでも動く、音声知覚研究のためのオールインワン Web アプリ。

## こんな方におすすめ

- 🎓 **音声学・言語学・心理学の研究者**
  - VOT 知覚、母音境界、L2 音素知覚の研究
  - 個人差・群差の心理測定関数を効率的に取得したい
- 🏥 **言語聴覚士（ST）・臨床音声学**
  - 患者の音韻識別能力・弁別能の評価
  - 治療前後の比較データの収集
- 📚 **音声学を教える教員**
  - クラスデモで「カテゴリ知覚」を可視化したい
  - 学生実験のためのプラットフォームが欲しい

## 4 つの対応パラダイム

| パラダイム | 用途例 |
|---|---|
| **Identification** | VOT 連続体の同定、母音境界の計測 |
| **AX discrimination** | 母語と非母語音の弁別能評価 |
| **AXB discrimination** | 3 刺激での音韻対立弁別 |
| **Rating** | 自然さ・典型性の心理評定 |

## 主要機能

### 実験デザイン
- 4 パラダイム対応（コード編集不要、設定パネルで切替）
- 練習試行・休憩・カウンターバランス・ITI/ISI
- 任意の刺激リスト（自由 wav ファイルを置くだけ）
- 注意逸脱（タブ切替）の自動検出・記録

### 被験者体験
- スマホ（iOS / Android）でそのまま動作
- 自動再生 + 失敗時の手動再生フォールバック（iOS 対応）
- 画面自動ロック防止（Wake Lock）
- 完全日本語 UI、所要時間は実験ごとに約 5〜10 分

### データ収集
- 被験者情報（氏名・生年月日・利き手・言語背景）の自動収集
- 試行データの**自動 Google Sheets 保存**（リトライ・エラー通知付き）
- 失敗時も被験者には成功表示、研究者には自動メール通知

### デモグラフィック調査
- 必須: 氏名・生年月日・性別・利き手・母語
- 任意: 第二言語 (AOA / 習熟度)・出生地・主に育った地域・方言・その他言語

### 結果表示
- 心理測定関数（continuumStep × 応答率）
- パラダイム別の自動グラフ（同定率・正答率・平均評価）
- カテゴリ境界の自動推定

## 技術スペック

- **言語**: HTML + CSS + JavaScript（フレームワーク不使用）
- **依存**: Chart.js v4（CDN）のみ
- **サーバー**: Google Apps Script + Google Sheets（**月額費用ゼロ**）
- **配布**: GitHub Pages / Netlify Drop / 大学サーバー等、静的ホスティングなら何でも可

## よくある質問

**Q. プログラミングは必要ですか？**
A. 不要です。設定パネルで全項目を変更できます。エンジニアでない研究者でも 30 分で実験設定が完了します。

**Q. 自分の刺激音を使えますか？**
A. はい。wav / mp3 / m4a / ogg など主要な音声形式が使えます。フォルダに置いて設定パネルでファイル名を指定するだけです。

**Q. データはどこに保存されますか？**
A. 購入者ご自身の Google アカウント内のスプレッドシートです。labphonlab は被験者データに一切アクセスできません。

**Q. 倫理審査は通りますか？**
A. ライセンスには IRB テンプレート（Pro プランのみ）と被験者向けプライバシーポリシー雛形を同梱しています。多くの研究機関で承認実績があります（※ ただし最終的な承認は購入者の所属機関の判断によります）。

**Q. SaaS 版はありますか？**
A. 現時点では買切のみです。需要があれば SaaS 版も検討予定です。

**Q. 返金は？**
A. デジタル商品の性質上、返金は原則承れません。販売前に**必ずライブデモで動作確認**してください。
